# PDF Conversion Reference

Use this reference when PDF work requires conversion APIs instead of direct drawing APIs.

## HTML to PDF

For complex HTML with CSS, scripts, assets, or URLs, use the Syncfusion HTML-to-PDF converter instead of `PdfHTMLTextElement`.

Official documentation:

- <https://help.syncfusion.com/document-processing/pdf/conversions/html-to-pdf/net>
